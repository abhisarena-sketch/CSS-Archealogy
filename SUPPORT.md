# Support

- **Questions and usage help:** open a [GitHub Discussion](https://github.com/abhisarena-sketch/CSS-Archealogy/discussions)
  or an issue labelled `question`.
- **Bugs and false positives:** open an [issue](https://github.com/abhisarena-sketch/CSS-Archealogy/issues). For a false
  positive, include the finding from `css-archaeology explain CSSA-xxxx`, the selector and a minimal example of the
  markup or code that uses it. False-positive reports are treated as bugs.
- **Security issues:** do not open a public issue. See [SECURITY.md](SECURITY.md).

CSS Archaeology is maintained by Workfonic Labs on a best-effort basis. There is no paid support.
