# css-archaeology

**Understand your CSS. Find what is hiding beneath it.**

The command line interface for [CSS Archaeology](https://github.com/abhisarena-sketch/CSS-Archealogy) by Workfonic Labs:
a static analyzer for potentially unused selectors, duplicate and overridden declarations, specificity conflicts,
media query issues and repeated values, with evidence and a confidence score for every finding.

```sh
npx css-archaeology scan
npx css-archaeology explain CSSA-0001
```

Requires Node.js 20.9 or later. Never executes scanned code and never modifies source files.
